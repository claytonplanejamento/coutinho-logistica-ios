# Coutinho Logística — versão iOS (PWA)

Esta versão foi preparada para iPhone e iPad.

## Como instalar no iOS/iPadOS
1. Publique estes arquivos em HTTPS (GitHub Pages, Vercel ou domínio próprio).
2. No iPhone/iPad, abra o endereço pelo Safari.
3. Toque em Compartilhar.
4. Toque em “Adicionar à Tela de Início”.
5. Abra pelo ícone Coutinho Logística.

## Permissões
No primeiro uso, permita Câmera e Localização quando o Safari solicitar.

## Limitação importante do iOS
A PWA registra GPS enquanto o app está ativo, inclusive no momento da baixa. O iOS pode suspender rastreamento contínuo quando a tela bloqueia ou o app vai para segundo plano.

## Para um app iOS nativo
Para gerar um .ipa/TestFlight/App Store é necessário um Mac com Xcode e assinatura Apple Developer. Este pacote PWA não exige App Store.
